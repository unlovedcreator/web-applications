## Шпаргалки
1. Создание проекта на Django - `django-admin startproject Project`.
2. Создание приложения в проекте - `python manage.py startapp app`.
3. Регистрация приложения - в settings.py, в списке `INSTALLED_APPS`.
4. Запуск проекта - `python manage.py runserver`.
5. Добавление адресов - в project/urls.py, настройка контроллеров - в views.py.
6. Добавление вложенных маршрутов - в app/urls.py.
7. Создание миграции - `python manage.py makemigrations`.
8. Выполнение миграции - `python manage.py migrate`.
9. Переход в ORM Django - `python manage.py shell`.
10. Добавить данные в БД можно разными способами:
    - создание нового объекта через импорт (from app.models import Model), присвоение новой переменной, добавление через `save()`;
    - создание переменной с пустым объектом класса, заполенение полей через ключи, сохранение через `save()`;
    - создание через `Model.objects.create` (также возвращает значение).
11. Вывод отсортированных значений - `Model.objects.filter(id=1)`.
12. Получение значения по ключу - `Model.objects.get(id=1)`.
13. Удаление записи - `Model.objects.delete(id=1)`.
14. Исключение записи - `Model.objects.exclude(id=1)`.
15. Регистрация приложения для админки - `from .models import Model` и `admin.site.register(Model)`. Выполняется в app/admin.py.
16. Добавление полей в админке - класс с `list_display` и его регистрация там же.
17. Добавление своих наименований для админки - методы `verbose_name` и `verbose_name_plural` в нужных местах.
18. Изменение языка отображения - либо `LANGUAGE_CODE = 'ru'`.
